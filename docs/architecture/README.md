# Decisiones de arquitectura

Este directorio almacenará diagramas y registros de decisiones de arquitectura (ADR). Cada decisión relevante deberá indicar contexto, alternativas, decisión y consecuencias.

Decisiones pendientes del Sprint 1:

- Versiones compatibles de Node.js, Angular e Ionic.
- Organización interna del front-end y back-end.
- Autenticación y autorización.
- Convenciones y versionado de la API REST.
- Acceso a Oracle, migraciones y manejo de transacciones.
- Estrategias de pruebas, logging y gestión de configuración.
