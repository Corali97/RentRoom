# Sprint Retrospective – Sprint 1

## Proyecto
RentRoom – Grupo 10

## Objetivo de la retrospectiva
Analizar el trabajo realizado durante el Sprint 1, identificando aspectos positivos, dificultades y oportunidades de mejora para los próximos Sprints.

## Aspectos positivos
- Se logró organizar el proyecto y definir claramente su problemática, objetivos y alcance.
- Se establecieron responsabilidades para las integrantes del equipo.
- Se estructuró el Product Backlog inicial y la planificación del proyecto.
- Se incorporaron Trello y GitHub para mejorar el seguimiento y la trazabilidad.
- Se avanzó en el diseño inicial y el modelo de datos de RentRoom.

## Aspectos a mejorar
- Mantener las evidencias del proyecto organizadas y actualizadas.
- Actualizar periódicamente el estado de las tareas en Trello.
- Fortalecer la documentación técnica a medida que avance la implementación.
- Mantener sincronizados los avances registrados en Trello, GitHub y la documentación académica.

## Acciones para el siguiente Sprint
- Continuar con el diseño y la implementación progresiva del proyecto.
- Mantener actualizado el Burndown Chart y el seguimiento de tareas.
- Registrar las decisiones técnicas relevantes y las evidencias generadas.
- Revisar al cierre del próximo Sprint el cumplimiento de las actividades planificadas.
